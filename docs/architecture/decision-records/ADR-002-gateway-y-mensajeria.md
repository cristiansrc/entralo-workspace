## Alternativas y consecuencias
- HTTP API+CloudFront/WAF **para APIs** no seleccionado, distinto del CloudFront de imágenes approved seleccionado. Menor request cost, exige guard origen/normalización; no dos authorizers. No desplegar ambos diseños API simultáneamente.
- HTTP API sin edge/guard descartada; REST más caro elegido por protección WAF nativa y menor complejidad operativa.
- Spring Cloud Gateway adicional, FIFO universal, RabbitMQ/Kafka y SNS+EventBridge obligatorios descartados por falta de caso/preferencia.

## Acceptance criteria
ADR2-AC1: público sin login, execute-api/origin/alias sin workload no llega al owner; WAF no se omite con token. Uniformidad404/429/503 y buyer no admin. ADR2-AC2: duplicados/reorder Standard conservan guardas/invariantes. ADR2-AC3: retención/visibility/receive count no multiplican envíos financieros ni borran obligación. ADR2-AC4: una ruta catálogo compuesto I-21 y verificación Ticketing I-25, workload público no muta; caída Purchases→UNKNOWN. Ver PLAN-02/05 propuesta.

ADR2-AC5/HB-01: clientes con IP distintas detrás mismo proxy se limitan por separado en Vercel; forwarded falsificado no cambia clave. HB-02: token comprador válido sin workload/host admitidos no accede directamente a Gateway/owner ni previews. HB-03: carga pública se bloquea en Vercel antes de AWS, Gateway sólo atribuye origen proxy y conserva WAF para webhook; prueba registra public_rate_limit_total{layer}, origin_guard_rejected_total y channel_transport_total sin IP cruda. HB-04: caída BFF/transporte no activa camino alterno. Pendiente verificación independiente/runtime, no cierre atribuido al Architect.

ADR2-AC6: I3/HB CDN público authorized/privado Catalog/quarantine deny; PDF auth/range/caps3MB/body4MB/4.5MBabsoluto, fiscal grande413+referencia externa protegida sin ALB público, image POST10MiB+1byte deny. ADR2-AC7: I1/HB cuotas reales/doble salto/carga/NAT/COUNT→BLOCK y firma MP denegada, SAR04 anti-bot sin máximo cuentas nuevo. ADR2-AC8/SES-01…04 políticas fuente/TopicArn/IAM/envelope/dedup/desorden/ambas DLQ, URL cert nunca fetch, cero email/compra extra. ADR2-AC9 SAR07/09 visibilidad30s/5s/heartbeat/duplicates/leases crash sin hold renovado, métricas/alertas exactas. Proposed, no aprobación humana.
